# Deye SG04LP3 and SG05LP3 Three-Phase LV

Reserved catalog-set directory for the future bundle format.

Planned map files:

- `catalog-index.yaml` - immutable release manifest and checksums.
- `telemetry.yaml` - read-only values supported by Solarman TCP and RS485.
- `telemetry-plus.yaml` - read-only values supported only by Solarman TCP.
- `control.yaml` - separately armed, validated commands with read-back.

The current released catalog remains at `../../../../deye-solarman-diagnostics/deye_sg04_sg05_3ph_lv_catalog.yaml` until the bundle-loader migration is implemented.
