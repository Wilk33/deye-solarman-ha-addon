# Applications in SolarMan Diagnostics 2.0.2

`apps/deye-solarman/src/deye_solarman_diagnostics` contains the application entry point and both transport adapters:

- `solarman.py` for SolarMan TCP;
- `rs485.py` for direct Modbus RTU through USB-RS485.

The shared runtime is in `packages/deye_inverter_core`. The only Home Assistant installable directory is `deye-solarman-diagnostics`, whose rootfs copy is generated by `tools/package_addon.py`.

Source application directories do not contain `config.yaml`, so Home Assistant Supervisor does not expose them as additional add-ons.
